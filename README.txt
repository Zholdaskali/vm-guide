ГАЙД ДЛЯ GITHUB PAGES

1. Загрузите index.html и .nojekyll в корень отдельного репозитория.
2. Settings → Pages → Source: Deploy from a branch.
3. Branch: main (или фактическая ветка с файлами), Folder: / (root), Save.
4. Дождитесь публикации; адрес будет показан в Pages.

Все шесть GIF встроены в index.html. Дополнительные файлы не нужны.
Публично размещается только гайд. Конструктор, VM, регистрация и пульт не размещаются на Pages.
Для практики студенты используют ссылку и Wi-Fi преподавателя.
На странице не подставляется адрес GitHub как адрес конструктора.
